# Immunization Data Analysis
## Project Overview
This project uses Python to analyze a sample immunization dataset and calculate vaccination coverage across five fictional regions.
## Objectives
- Calculate vaccination coverage for each region.
- Calculate overall vaccination coverage.
- Practice basic data analysis using Python.
- Learn version control using Git and GitHub.
## Dataset
The dataset is stored in `data/sample_Immunization.csv`.
It contains:
- Region
- Children surveyed
- Children vaccinated
**Note: ** The dataset contains fictional numbers for educational purposes only.
## Tools Used
- Python
- Git
- GitHub
- CSV dataset
## How to Run the Project
1. Install Python and Git.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:
   `python Immunization_analysis.py`
## Expected Output
The script calculates vaccination coverage for each region and reports the overall coverage.
- Total children surveyed: 500
- Total children vaccinated: 413
- Overall vaccination coverage: 82.6%
